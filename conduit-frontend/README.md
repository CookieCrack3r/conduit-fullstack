# Conduit Frontend

Angular client, forked from [gothinkster/angular-realworld-example-app](https://github.com/gothinkster/angular-realworld-example-app) (MIT, see `LICENSE`).

Setup, configuration and deployment are documented in the [root README](../README.md).

> The upstream project's own instructions no longer apply to this containerised
> setup. In particular, `src/environments/environment.ts` is **generated** by
> `scripts/set-env.js` from the `API_URL` variable — editing it by hand has no
> effect, because the next build overwrites it.
