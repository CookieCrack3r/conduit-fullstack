# Conduit Backend

Django REST API, forked from [gothinkster/productionready-django-api](https://github.com/gothinkster/productionready-django-api).

Setup, configuration and deployment are documented in the [root README](../README.md).

> The upstream project's own instructions no longer apply to this containerised
> setup. They describe a manual pyenv installation of Python 3.5.2, which the
> container image replaces — the runtime is pinned in `Dockerfile` instead.
